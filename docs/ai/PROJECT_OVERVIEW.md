# School Trainer — обзор проекта

## Назначение

Единое веб-приложение-тренажёр для школьников России (ориентир: 3–8 классы). Первый этап: **5 класс** по предметам: русский язык, английский язык, математика.

## Контекст

Исходные самостоятельные PWA-проекты (источники UX и доменной логики на старте):

- Английский: `english-learning-pwa`
- Математика: `math-learning-pwa`
- Русский: `russian-language-pwa`

Цель объединения: один интерфейс, общая модель пользователя и прогресса, общий контент-пайплайн, упрощение дальнейшей интеграции с мобильным приложением родительского контроля **Altakid** (Kotlin).

## Продуктовые акценты

- Учебные материалы и задания должны **покрывать учебную программу** по мере развития продукта; контент хранится **вне хардкода** (БД или эквивалентное хранилище версионируемого контента).
- Задания и уроки — **интерактивные**, с понятной подачей и обратной связью для ученика.

## Границы первой версии (ожидаемо)

Фокус на архитектуре объединения, модели данных для контента класса 5 и скелете приложения; масштабирование на другие классы закладывается в модели и API без переписывания всего приложения.
